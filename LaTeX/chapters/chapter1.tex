\chapter{Introduction}\label{chp:1}

The goal of any supervised learning problem is to develop a model to infer an unknown relationship between the input data (features) and output data (labels for classification or outcome for regression) from the training samples. This predicted relationship, then, can be used to estimate the output values (labels or outcome) for unseen test input data points. Traditionally, while building a supervised learning model, we commonly assume that the training and test data are drawn from the same distribution, i.e., the input points in the training set and the input points used for testing follow the same probability distribution \citep{bishop1995neural, Duda2001, vapnik1998statistical, hastie2009elements}.\\

However, in real-world applications, this assumption is frequently violated due to multiple reasons. When this assumption is violated, standard empirical risk minimization (ERM) can lead to models that fail to generalize poorly for the new, unseen data from the test distributions. This phenomenon is known as \textcolor{blue}{\emph{covariate shift}}, where the marginal distribution of the input features differs between training and test data while the conditional distribution of the output given the input remains unchanged \citep{shimodaira2000improving}. This shift often occurs due to biases in data collection, domain variations, or changes in the underlying data-generating process \citep{sugiyama2000covariate}. This is very common in real-world applications such as medical imaging, finance, and NLP (Natural Language Processing), where the data acquisition process introduces sampling bias.\\

\emph{Covariate shift poses a significant challenge in supervised learning}, as it can significantly degrade the performance of the machine learning models. It arises in various applications, including off-policy reinforcement learning \citep{shelton2001importance}, spam filtering \citep{bickel2007dirichlet}, bioinformatics \citep{baldi1998bioinformatics, Borgwardt2006}, and brain-computer interfacing \citep{wolpaw2002brain}. Additionally, in economics, sample selection bias \citep{heckman1979sample} can also manifest as a form of covariate shift.\\

The goal of this project is to explore the problem of covariate shift in supervised learning through the lens of kernel methods, particularly in the linear regression settings. We examine theoretical foundations, key methodologies in mitigating covariate shift using kernel-based learning techniques in supervised learning context.
